OVERVIEW

스퍼터링이
닿지 않는 곳까지.

SOC-12F는 (주)세미안의 시그니처 오스뮴 코터입니다. SOC-12N의 검증된 CVD 코팅 성능에 흄 통합 시스템과 자동 시료 교환 시스템(특허 KR 10-2289120)을 추가한 국내 전용 모델로, 다공성·복잡 구조 시료에도 균일한 비정질 박막을 형성합니다.

안전 구조는 5단계입니다 — Flash 소량 주입, 메인 챔버 코팅, 보조 챔버 1차 제거, 활성탄 2차 트랩, HEPA 3차 최종 트랩. 흄 케이스 부압 유지로 외부 누출까지 차단합니다.

"오스뮴 코터 도입 후 FE-SEM 100,000× 관찰에서 박막 입자가 사라져 분석 결과를 그대로 논문에 사용할 수 있게 되었다. 가스 노출 우려 없이 운영진 누구나 사용할 수 있다."

Standard SEM Imaging

일반 SEM 관찰을 위한 비정질 박막 형성. 100,000× 미만 배율에서 표면 디테일을 그대로 보존하며, 금속 코팅 대비 입자 미관측으로 분석 품질을 한 단계 끌어올립니다.

  • OsO₄ Flash Mode 0.5초 × 3 펄스 — 가스 사용량 최소화
  • 듀얼 밸브 가스 제어 + Sealed Cartridge로 사용자 노출 0
  • FTM 0.1 nm 실시간 두께 모니터링
SEM Imaging 응용 가이드

FE-SEM 고분해능

100,000× 배율 이상에서도 박막 입자가 보이지 않는 비정질 박막의 표준. 나노 단위 미세 구조 분석, 차세대 메모리·반도체 박막 연구에 최적.

  • OsO₄ 비정질 박막 — grain boundary 없음
  • FE-SEM 한계 분해능 도달
  • Sealed Cartridge로 박막 순도 보장
High-Resolution 응용 가이드

TEM 시료 전처리

Glow Discharge 유닛이 본체에 통합되어 별도 표면처리 장비 없이 TEM 시료 전처리가 가능합니다. 친수성·소수성 표면 변환 → 분자 분산·부착 개선.

  • Glow Discharge 통합 — SEM·TEM 한 장비에서
  • 친수성·소수성 응용 모두 가능
  • 워크플로우 시간 단축
TEM & Analytical 응용 가이드

다공성 · 복잡 구조 시료

CVD (Chemical Vapor Deposition) 방식은 스퍼터링과 달리 가스 확산을 통해 시료 표면을 코팅하므로, 촉매·MOF·다공성 폴리머 등 복잡 구조 시료의 미세 형상을 그대로 보존하면서 균일하게 코팅합니다.

  • CVD 가스 확산 — 시료 내부까지 코팅 도달
  • 다공성 구조 보존
  • 스퍼터링이 닿지 않는 표면도 코팅

생물·세포·조직 시료

섬세한 생물학적 시료의 미세 구조를 손상 없이 보존하는 표준. Flash Mode의 짧은 펄스로 열 영향 최소화, 비정질 박막으로 분석 품질 극대화.

  • Flash Mode — 짧은 펄스로 열 손상 차단
  • 분자 단위 미세 구조 보존
  • 안전 5단계 가스 차단 — 생물 연구실 적합

Features

5 핵심 기술
01 · FUME AUTO SAMPLE EXCHANGE · PATENTED

버튼 한 번,
시료가 알아서 들고나갑니다.

Fume Sample Auto Loading/Unloading 시스템(특허 KR 10-2289120)은 흄 케이스 부압을 유지하면서 시료 교환을 완전 자동화합니다. 버튼을 누르면 메인 챔버가 자동 상승하고 스테이지가 흄 케이스를 열고 사용자 쪽으로 이동, 시료 안착 후 자동 후퇴 → 진공 → 코팅이 자동 진행됩니다.

  • 흄 케이스 개방 불필요 — 사용자 가스 노출 0
  • 한국 특허 KR 10-2289120 적용
  • SOC-12F만의 차별 기능 (SOC-12N에는 없음)
02 · GAS LEAK PREVENTION · PATENTED

오스뮴 가스 노출
0을 목표로 한 설계.

오스뮴 테트라옥사이드(OsO₄)는 강력한 독성 가스. SOC-12F는 이를 다루는 5단계 안전 구조와 지속적 부압 유지(외기 흡입)로 사용자 노출을 원천 차단합니다. 특허 KR 10-2096523.

  • ① Flash 소량 펄스 주입 — 가스 사용량 최소화
  • ② 메인 챔버 코팅 — Sealed Cartridge 진공 절단
  • ③ 보조 챔버(Auxiliary Chamber) 1차 제거
  • ④ 활성탄 2차 트랩
  • ⑤ 활성탄 + HEPA 3차 최종 트랩

03 · FLASH MODE

결정화 없는
비정질 박막.

0.5초 펄스를 3회 반복하는 Flash Mode는 미반응 가스 배출을 최소화하고 앰플 수명을 연장합니다. 결정화를 방지하며 듀얼 밸브로 정밀한 가스 제어 — 100,000× 배율에서도 입자 미관측의 균일한 박막을 보장합니다.

  • FE-SEM 10만배 관찰에서도 박막 입자 보이지 않음
  • 가스 사용량 최소화 → 앰플 수명 연장
  • 듀얼 밸브로 정밀 제어
SEALED CARTRIDGE
진공 중 절단
04 · SEALED CARTRIDGE

앰플은 진공 안에서
열립니다.

OsO₄ 앰플을 진공 챔버 안에서 절단하는 방식. 일반 코터처럼 대기 중 절단할 때 발생하는 가스 노출이 0이 됩니다. 작업자가 가스를 직접 만질 일이 없습니다.

05 · INTEGRATED GLOW DISCHARGE

TEM 전처리까지
한 장비에서.

Glow Discharge 유닛이 본체에 통합되어 별도의 표면처리 장비 없이도 TEM 시료 전처리가 가능합니다. 친수성·소수성 표면 변환을 손쉽게 — 장비 한 대로 SEM·TEM 두 영역 모두 커버.
