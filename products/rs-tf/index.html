OVERVIEW

박막 응용의
새로운 기준.

RS-TF는 단순한 전처리를 넘어 고품질 박막 증착에 최적화된 고사양 모델입니다. 자동 WD 거리 조절 시스템으로 열 손상을 최소화하면서 균일도를 향상시키고, 액티브 셔터를 통한 프리 스퍼터링으로 고품질의 박막 응용이 가능합니다.

QCM 센서가 샘플 스테이지와 일체형으로 결합되어 함께 이동하므로, 시료의 위치와 동일한 조건에서 실시간으로 두께를 감지해 재현성 있는 박막을 보장합니다. 대면적 균일도(Planetary Rotation) 옵션으로 까다로운 증착 조건까지 유연하게 대응.

Features

SAMPLE / DIAGRAM
실제 이미지 추가 예정
01 · AUTO WD CONTROL

자동 WD 거리
조절 시스템.

열에 민감한 시료 보호와 균일도 향상을 위한 필수 기능. 공정을 시작하고 타겟과 시료 간의 거리(Working Distance)를 터치패드로 조절해 플라즈마 열에 의한 손상을 최소화하며, 코팅 종료 시 로딩 위치로 자동 복귀해 편의성을 극대화했습니다.

SAMPLE / DIAGRAM
실제 이미지 추가 예정
02 · STAGE-INTEGRATED FTM

시료와 함께 움직이는
정밀 두께 제어.

QCM(수정 진동자) 센서가 샘플 스테이지와 일체형으로 결합되어 함께 이동(Moving Together)합니다. 시료의 위치와 동일한 조건에서 실시간으로 두께를 감지해 위치 차이로 인한 측정 오차를 최소화, 동일한 코팅 조건을 재현할 수 있습니다.

SAMPLE / DIAGRAM
실제 이미지 추가 예정
03 · ACTIVE SHUTTER

고순도 박막을 위한
프리 스퍼터링.

증착이 시작되기 전, 셔터가 닫힌 상태에서 타겟 표면의 오염원을 제거하는 프리 스퍼터링이 가능합니다. 이후 깨끗한 상태의 입자만을 시료에 증착시켜 박막의 순도(Purity)를 한층 더 높여줍니다.

SAMPLE / DIAGRAM
실제 이미지 추가 예정
04 · PLANETARY ROTATION (OPTION)

유성 회전으로
대면적 균일도.

시료가 자전과 공전을 동시에 수행하는 플래너터리 로테이션(Planetary Rotation) 메커니즘을 통해 넓은 면적의 웨이퍼나 굴곡이 심한 복잡한 형상의 시료에서도 두께 균일도(Uniformity)를 향상시킵니다.

Applications

  • 고품질 박막 증착 연구
  • 고분해능 FE-SEM 시료 코팅
  • EDS·EBSD 분석용 정밀 박막
  • 복잡 형상 시료 (Planetary 옵션)
  • 대면적 웨이퍼 균일 코팅
  • 박막 순도가 중요한 응용
