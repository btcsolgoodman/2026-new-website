SOC-12N
Advanced Osmium Coater.

Innovative Osmium Coater that combines safety and convenience. Sealed Cartridge, Flash Method, Auxiliary Chamber — 글로벌 분석 표준을 만족하는 오스뮴 코터의 베이스 모델.

OVERVIEW

정밀과 안전을
한 시스템에.

오스뮴 코팅은 비정질(amorphous) 박막을 형성해 최고 분해능 관찰과 나노 응용 연구에 탁월하며, 섬세한 생물·섬유 시료의 미세 구조를 그대로 보존합니다. 다만 오스뮴 분말은 독성이 있어 취급 시 사용자 보호가 핵심입니다.

SOC-12N은 보조 챔버를 통한 잔류 오스뮴 효율적 제거, 가스 누출 감지 알람, 직접 접촉 없이 카트리지를 도입할 수 있는 Sealed Cartridge 시스템으로 안전 기준을 충족하면서도 CVD 코팅 방식과 Flash Mode로 일관된 고품질 박막을 형성합니다.

실제 이미지 추가 예정
01 · SEALED AMPOULE CARTRIDGE

직접 접촉 없이
오스뮴을 도입.

특허 출원 Sealed Cartridge 시스템으로 위험한 오스뮴과 사용자의 직접 접촉 없이 챔버에 도입할 수 있습니다. 카트리지는 쉽게 분리되어 청소·유지보수가 편리하며, 오스뮴 가스 누출 방지 메커니즘과 즉시 알람 시스템이 잠재 위험을 차단합니다.

SAMPLE / DIAGRAM
실제 이미지 추가 예정
02 · FLASH MODE + CVD

Flash Mode로
고품질 박막.

Flash Mode로 반응하지 않은 오스뮴 가스 방출을 최소화하고 오스뮴 소비량을 줄이며 응축(condensation)을 막아 SEM·TEM 고품질 이미지를 보장합니다. 듀얼 밸브 정밀 가스 제어로 장기간 미사용 후에도 일관된 결과를 얻을 수 있습니다.

SAMPLE / DIAGRAM
실제 이미지 추가 예정
03 · AUXILIARY CHAMBER

잔류 오스뮴
효율적 제거.

보조 챔버가 잔류 오스뮴을 효율적으로 제거해 깨끗한 실험실 환경을 유지합니다. 메인 챔버의 가스 감지 센서가 오스뮴 앰플 교체 시점을 자동 알람으로 알려주며, CVD 방식으로 다공성·복잡 형상 시료에도 균일한 코팅이 적용됩니다.

Applications

  • 최고 분해능 SEM·TEM 이미징 (비정질 박막)
  • 나노 응용 연구 시료 코팅
  • 섬세한 생물·섬유 시료 (구조 보존)
  • 다공성·복잡 형상 시료 (CVD 균일 코팅)
  • 분석 워크플로우 표준 박막 증착
